# Neo-Brutalist Iconography Rules (Strict No-Emoji Policy)

- **ASLA EMOJİ KULLANILMAYACAK**: Arayüzde, butonlarda, toast mesajlarında, tabelalarda ve başlıklarda asla standart Unicode emojiler (⛽, 🚗, 🏗️, 🚚, 📊, 💰, vb.) kullanılmayacaktır.
- **BRUTALİST SVG İKONLAR**: Tüm ikonlar temiz, geometrik, 2px/2.5px stroke kalınlığına sahip, sert açılı inline SVG formatında veya CSS ile stillendirilmiş brutalist vektör ikonlar olarak tasarlanacaktır.
